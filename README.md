# TRENER

Personalny trener przygotowujący mnie na Hyrox — listopad 2026, Poznań.

## Rozliczenie dnia

`index.html` to prosta, mobilna aplikacja (jeden plik, bez internetu) do codziennego
rozliczania treningu i regeneracji. Dane zapisują się lokalnie w przeglądarce
(`localStorage`) — nic nie wychodzi na zewnątrz.

### Co można zapisać
- **Trening**: zrobiony / częściowo / dzień wolny / opuszczony
- **Typ**: bieg, siłowy, Hyrox / stacje, interwały, mobilność
- **Metryki**: czas, dystans, sen, woda, waga, białko
- **8 stacji Hyrox**: SkiErg, Sled Push, Sled Pull, Burpee Broad Jump, Rowing,
  Farmers Carry, Sandbag Lunges, Wall Balls
- **Energia / samopoczucie** oraz **ocena dnia** (1–10)
- **Notatki**

### Historia i podsumowanie
- Lista wszystkich dni (kliknij, aby edytować)
- Liczba dni, **seria 🔥** (dni pod rząd), średnia ocena
- Eksport wszystkich danych do JSON

### Jak używać
Otwórz `index.html` w przeglądarce na telefonie lub komputerze. Można dodać do
ekranu głównego jako skrót — działa też offline.
